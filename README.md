# Portfolio

Portfolio personal de Jesús Lobato González construido con Angular, PrimeNG y Tailwind CSS.

## Desarrollo

```bash
npm start
```

La aplicación se sirve por defecto en `http://localhost:4200/`.

## Validación

```bash
npm test
npm run build
```

## Estructura

El contenido del portfolio vive directamente en el template de la home para mantener la edición sencilla. El componente TypeScript conserva solo la interacción necesaria para el menú móvil, el estado del header al hacer scroll y el año del footer.
